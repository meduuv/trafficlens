# trafficlens

Read-only network traffic summarizer for analyzing captured flow records.

## Scope

TrafficLens is designed for defensive analysis of data you already have. It does not generate packets, exploit services, or perform intrusive scanning.

## Planned capabilities

- Aggregate flows by endpoint and protocol
- Count packets and bytes
- Summarize duration and throughput
- Export machine-readable JSON

## Development

The project is intentionally small and dependency-light.
